# Security policy

## Supported versions

Only the latest release on the `main` branch is supported. Fixes are released as a
new patch version (for example 1.0.1).

## Reporting a vulnerability

Please do not report security problems in a public issue.

Use **Security → Report a vulnerability** on this repository to send a private report.
Describe the problem, the steps to reproduce it and, if you know it, the affected file.
You will get a reply as soon as possible, and the fix will be credited to you in the
changelog unless you prefer otherwise.

Both tools are desktop programs that run locally. The parameterization GUI writes and
runs shell scripts that call AmberTools on your own machine; neither tool sends data
anywhere.
